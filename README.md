# 지우 영어 학습 보고서

배포: https://tutor-report.pages.dev

순수 HTML/CSS/JavaScript 정적 보고서입니다. 한 번에 한 섹션만 표시하며, 본문 아래의 이전·다음 버튼으로 이동합니다. 상단 목차 선택, 브라우저 뒤로/앞으로 가기, 섹션 직접 링크(#s06 등)를 지원합니다. JavaScript가 꺼져 있거나 인쇄할 때는 전체 섹션을 표시합니다.

## 로컬 확인

`index.html`을 직접 열거나 `node preview.cjs` 실행 후 http://localhost:4173 에 접속합니다.

## 이미지

사용자가 업로드한 `이번.zip`의 사진 6장, `지난.zip`의 사진 3장을 확인했습니다. 지난 시험은 1~3쪽만 제공되어 서술형 전체를 비교하지 않았습니다.

`assets/`에는 실제 사진의 필요한 부분을 회전·크롭·축소한 이미지 7개가 있습니다. 필기 추가·삭제나 생성형 보정은 하지 않았습니다. `crop-sources.json`에 원본 파일과 크롭 좌표를 기록했습니다. 좌표는 EXIF 방향을 적용한 세로 사진을 1368×1824 기준으로 환산한 값입니다.

- previous-writing: 지난 기말 3쪽 서술형 1번
- current-writing-1/2: 이번 중간 2쪽 서술형 1·2번
- current-writing-4: 이번 중간 5쪽 서술형 4번
- bridge: 이번 중간 3쪽 서술형 3번 제시문 및 빈 답안란
- the-dot: 이번 중간 4쪽 본문 표시
- self-discovery: 이번 중간 5쪽 20·21번 선택지 표시

밑줄 중 문제에 인쇄된 것을 학생의 필기로 해석하지 않습니다. 필기의 작성 시점·작성자는 사진만으로 확인할 수 없으며, 복수 표시로 최종 선택이 불명확한 경우 이를 구분해 적었습니다. 시험 점수는 교사가 제공한 19→21점을 사용합니다.

## 디자인과 확인

화이트 배경, 단일 본문 폭, Pretendard 글꼴. 글꼴 로드 실패 시 시스템 글꼴로 표시됩니다. 기업 홈페이지형 표지·영문 장식·슬로건·메타 설명을 제거했습니다. 모바일·PC에서 한 섹션 표시, 목차·이전·다음·뒤로 이동, 이미지 로드 및 가로 넘침을 확인합니다.

검색 색인 제외 설정(noindex)은 접근 제한 기능이 아닙니다.
