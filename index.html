07. 본문의 표시와 답안

The Dot

본문의 일부 번호 주변에 필기 표시가 있습니다. 번호가 붙은 문장 아래의 밑줄은 문제에 인쇄된 것으로, 학생이 직접 찾은 근거 표시가 아닙니다.

Bridge

서술형 3번의 제시문 옆에 영어 메모가 있지만, 아래의 ‘틀린 문장’과 ‘고친 문장’ 답안란은 비어 있습니다.

08. 긴 지문의 핵심 파악

Self-discovery의 20번에는 ⑤가 표시되어 있습니다. 21번에는 ④와 ⑤ 주변에 표시가 함께 있어 사진만으로 최종 선택과 수정 순서를 구별하기 어렵습니다.

이 답안만으로 긴 지문의 핵심 파악 능력이 전보다 나아졌다고 보기는 어렵습니다. 다음 수업에서는 핵심을 한 문장으로 말하고 근거 문장을 찾아 설명하게 하겠습니다.

09. 아직 점수로 연결되지 않는 이유

어휘 정확도

영영풀이와 비슷한 형태의 단어를 구별하는 연습이 필요합니다. 단어의 뜻을 확인하고 문맥에 맞게 선택하는 훈련을 이어가겠습니다.

문법·어법 적용

배운 규칙을 실제 문장에서 찾아 적용하는 데 어려움이 있습니다. 문법 문제를 풀 때 동사 형태와 문장 구조를 직접 확인해야 합니다.

서술형 문장 구성

이번 서술형 1·2번에는 일부 단어를 적었지만 완전한 문장을 만들지 못했습니다. 짧은 문장부터 어순과 동사 형태를 맞추어 쓰는 연습이 필요합니다.

10. 시험 준비에서 아쉬웠던 점

과제가 충분히 수행되지 않아 다음 수업에서 이전 내용을 다시 학습하는 데 시간이 들었습니다. 진도가 늦어지면서 반복 문제풀이와 실전·서술형 훈련량이 줄었습니다.

다음에는 과제를 수행 가능한 분량으로 정하고, 수업 시작 때 완료 여부와 이해도를 확인하겠습니다.

11. 학습 태도와 문제풀이 과정

이미 배운 기본 문제에서도 요구를 충분히 읽거나 근거를 확인하지 않은 채 답을 골라 틀리는 경우가 있었습니다. 다시 생각해 보도록 요청하면 별도의 설명 없이 정답을 찾는 경우도 반복되었습니다.

내용을 더 배우는 것과 함께, 알고 있는 내용을 스스로 확인하고 적용하는 과정이 필요합니다.

교사는 풀이 방법을 안내하고 연습을 도울 수 있지만, 학생 대신 문제를 읽고 근거를 판단해 줄 수는 없습니다. 지우가 직접 생각하고 답을 결정하는 과정에 참여해야 수업에서 배운 내용이 시험에서도 활용될 수 있습니다.

과제 복습과 독립적인 풀이가 이어지지 않으면 수업 시간 상당 부분을 재학습과 개별 안내에 사용하게 됩니다. 그만큼 새 내용과 반복 연습에 쓸 시간이 줄어듭니다.

12. 다음 학습에서 바꿀 부분

  1. 과제 분량 조정

    필수 과제를 짧고 명확하게 정하고, 다음 수업 시작 때 수행 여부와 이해도를 확인합니다.

  2. 풀이 과정 확인

    문제의 요구 확인 → 근거 찾기 → 답 선택 → 제출 전 재확인의 순서로 풉니다.

  3. 오답 원인 구분

    몰랐던 내용, 적용이 어려웠던 내용, 확인을 생략한 경우를 나누어 다시 연습합니다.

  4. 서술형·실전 연습

    짧은 문장부터 혼자 쓰고 어순·동사·철자를 검토합니다. 본문 진도와 별도로 실전 연습 시간을 확보합니다.

13. 종합 평가

이번에는 기초 문장 훈련과 본문 독해·암기·암송·영작을 진행했습니다. 시험 점수는 19점에서 21점으로 2점 올랐지만, 학습한 내용이 충분한 정답으로 이어지지는 못했습니다.

어휘와 문법의 정확도, 서술형 문장 구성, 수업 사이의 복습을 보완해야 합니다. 이미 배운 문제를 풀 때도 요구와 근거를 확인하는 습관이 필요합니다.

다음 수업에서는 과제 수행 여부와 혼자 해결하는 과정을 확인하겠습니다. 가정에서도 정해진 과제를 마쳤는지 확인해 주시면 도움이 되겠습니다.
